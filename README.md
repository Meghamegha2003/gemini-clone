## 📌 About the Project

Gemini Clone is a web-based AI chatbot inspired by Google Gemini. It allows users to enter prompts and receive AI-generated responses using the Gemini API.

The application provides a clean, interactive interface with a modern AI chat experience.

## ✨ Features

- 🤖 AI-generated responses using the Gemini API
- 💬 Interactive chat interface
- ⚡ Streaming responses with a loading indicator
- 📝 User prompt input and submission
- 🔄 Send follow-up prompts
- 📱 Responsive user interface
- ⚛️ Component-based architecture using React

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd Gemini
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure the API Key

Create a `.env` file in the root directory and add your Gemini API key.

```env
VITE_GEMINI_API_KEY=your_gemini_api_key
```

Replace `your_gemini_api_key` with your actual API key.

**Security note:** Never upload your actual API key to GitHub. For production applications, use a backend to protect the key because Vite environment variables prefixed with `VITE_` are exposed to client-side code.

### 5. Run the Application

```bash
npm run dev
```

Open the local URL displayed in your terminal.
